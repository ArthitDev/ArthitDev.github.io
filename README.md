# arthitdev.github.io

Portfolio ของ อาทิตย์ ลุงหยะ (Arthit LungYa) — https://arthitdev.github.io/

เว็บ static ล้วน (HTML · CSS · JavaScript) ไม่ต้อง build

## แก้ไขเนื้อหา
- **ผลงาน / ทักษะ** แก้ที่ array `PROJECTS` และ `SKILLS` ด้านบนของ `script.js`
- **ข้อมูลส่วนตัว / การศึกษา / ช่องทางติดต่อ** แก้ใน `index.html`
- **สี / ฟอนต์** แก้ตัวแปรใน `:root` ของ `style.css`

## รันดูในเครื่อง
```bash
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000
